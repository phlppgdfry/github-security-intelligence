# Security policy

Found a security problem in `ghsi` itself (for example token leakage or unsafe handling of registry data)?
Please report it privately through
[GitHub private vulnerability reporting](https://github.com/phlppgdfry/github-security-intelligence/security/advisories/new),
not in a public issue. I aim to reply within 7 days.

Errors in the GitHub Advisory Database are not security issues in this repo: suggest the correction on the
advisory page (see [docs/first-advisory-credit.md](docs/first-advisory-credit.md)).
